前言为什么"分类"是投标第一课

本手册即【第一部分：决策闸门层】。投标助手把投标工作拆成6个优先级部分（见上方学习路径），第一部分最致命也最优先——拿标书先回答"该不该投"，再谈怎么写。下方采购方式 + 行业坑 + 决策前哨四步是第一部分骨架，本期另新增控标识别实战一章。

投标最常见的失误不是"标书写得差"，而是搞错战场——把货物标的逻辑套到服务标上，把公开招标的策略用到竞争性磋商里，把政府采购的政策红线当工程标处理。

核心方法论：两条轴定位法

┌─────────────────────────────────────┐ 采购方式轴 │ 公开招标 / 邀请招标 / 竞争性磋商 │ (怎么招) │ 竞争性谈判 / 询价 / 单一来源 │ └─────────────────────────────────────┘ ✕ (交叉定位) ┌─────────────────────────────────────┐ 行业类型轴 │ 工程 / 货物 / 服务 / 政府采购 │ (招什么) │ EPC / PPP │ └─────────────────────────────────────┘
两条轴交叉点 = 死亡陷阱分布。同一张招标文件，在不同象限里雷埋在不同位置。投标助手的核心能力，就是先帮你定位象限，再告诉你这个象限专属的雷区。

第一章采购方式六大门派

1.1 公开招标

依法必招 · 主战场
适用场景
  • 限额以上货物/工程/服务采购
  • 招投标法强制公开项目
  • 国企、事业单位大宗采购
核心机制
  • 公开发布招标公告
  • 综合评分法（商务+技术+价格）
  • 最低价 ≠ 中标
死亡陷阱
  • 实质性条款漏响应即废标（第一大废标原因）
  • 投标保证金截止前未到账（到账≠汇出；上限为估算价2%、须基本账户转出——实施条例第26条）
  • 投标文件递交超时（差一分钟即废）
  • 资格后审不过（证书/业绩/社保）
  • 围标串标认定（IP/MAC/报价规律）
报价策略
价格分反推限价；商务技术分先算赢面；梯度报价不报最低
决策清单
  • 资质门槛齐备？
  • 类似业绩达标？
  • 项目经理可锁定？
  • 限价有利润空间？
  • 实质性条款能逐条响应？

1.2 邀请招标

限制性竞争
适用场景
  • 仅少数投标人具备能力
  • 保密/安全/专利限制
  • 依法不公开的特殊项目
核心机制
  • 向3家以上发邀请书
  • 不公开发布公告
  • 评标同公开招标
死亡陷阱
  • 邀请程序违法被质疑（名单不透明）
  • 围标串标嫌疑放大（关联方聚集）
  • 资格预审材料造假→ 黑名单
  • 受邀方不足3家流标
报价策略
重点在合规非价格；防关联串标认定；报价贴近限价留空间
决策清单
  • 邀请资格合法取得？
  • 与其他方有关联关系？
  • 文件制作痕迹独立？
  • 报价无规律性差异？

1.3 竞争性磋商

服务与复杂项目首选
适用场景
  • 政府购买服务
  • 技术复杂/性质特殊
  • PPP / 专利专有技术
核心机制
  • 多轮磋商
  • 最后报价密封提交
  • 综合评分法
死亡陷阱
  • 磋商文件响应不彻底（逐条响应）
  • 最终报价超磋商范围即废
  • 磋商轮次控节奏失误
  • 提交最后报价超时
  • 磋商意见未书面留痕
报价策略
首轮高10-15%留空间；末轮一锤定音；关注磋商组倾向
决策清单
  • 磋商文件逐条对应？
  • 最终报价在磋商范围内？
  • 要求书面留痕？
  • 权重是否清晰？

1.4 竞争性谈判

紧急 / 技术不确定
适用场景
  • 紧急采购（抢险救灾）
  • 技术方案不确定
  • 招标后无合格标
核心机制
  • 多轮谈判
  • 最低价中标
  • 谈判后最后报价
死亡陷阱
  • 报价策略失误差价被砍
  • 谈判泄露底价（被对手参考）
  • 最后报价超采购预算即废
  • 技术方案调整未响应
  • 多家同价再报/抽签
报价策略
首轮高成本30-40%；末轮贴成本底线；不主动透露成本
决策清单
  • 采购预算已知？
  • 谈判轮次上限？
  • 技术方案可调整？
  • 报价在成本底线之上？

1.5 询价

标准现货货物
适用场景
  • 规格标准统一
  • 现货货源充足
  • 金额较小
核心机制
  • 3家以上一次报价
  • 不得更改
  • 最低价中标
死亡陷阱
  • 询价文件响应不全即废（逐项）
  • 报价超采购预算
  • 一次定终身无谈判机会
  • 交货期响应不到位
  • 样品/检测报告缺失
报价策略
一报价即终价精准报；算清成本+利润；报"次低"防质疑
决策清单
  • 询价文件逐项响应？
  • 报价在预算内？
  • 交货期可满足？
  • 样品/检测报告齐全？

1.6 单一来源

无竞争 · 高风险
适用场景
  • 只能唯一供应商
  • 紧急情况不可预见
  • 保证一致性/配套
核心机制
  • 无竞争性采购
  • 直接议价
  • 公示期社会监督
死亡陷阱
  • 价格合理性被质疑（对标行情）
  • 公示期遭异议/举报即终止
  • "唯一性"证据链不完整
  • 审批层级不够（省级财政）
  • 关联交易嫌疑
报价策略
价格对标3份行情；成本构成透明；首轮高20%留空间
决策清单
  • 唯一性证据链完整？
  • 价格合理性材料齐全？
  • 异议应对预案？
  • 审批层级合规？无关联？

第二章五大行业专属坑

2.1 工程招标

施工 / 勘察 / 设计 / 监理 / 工程总承包
围标串标认定
  • 电子标：IP/MAC/CPU序列号/硬盘序列号重合 → 属于"投标文件由同一单位或个人编制"情形（实施条例第40条），由评标委员会/监管部门结合认定
  • 文件痕迹：创建人/修改人/保存人一致 → 嫌疑
  • 报价规律性：等差/等比数列 → 嫌疑
  • 文件内容雷同：方案/错误表述一致 → 认定
项目经理锁定
  • 注册建造师不得同时在两个及以上项目任项目负责人（注册建造师管理规定第21条；三种除外情形见执业管理办法第9条）
  • 社保连续缴纳（通常6个月以上）
  • 证书有效且注册单位与投标人一致
  • 中标后不得更换（更换需建设单位同意）
类似业绩认定
  • 合同 + 竣工验收证明双件齐全
  • 金额/规模/类型匹配"类似工程"定义
  • 时间范围通常近3-5年
  • 部分项目要求业绩项目经理与本次一致
履约保证金
比例 ≤ 中标合同金额10%（实施条例第58条）；方式：银行保函/担保保函/现金；退还时限以合同/招标文件约定为准（"验收合格后28天内"为常见约定，非统一法条）
农民工工资保证金
工程类强制；单独账户、专款专用；未存储影响开工
应对策略
  • 投标文件独立制作：独立IP/设备/人员，杜绝痕迹重合
  • 项目经理查档：投标前"四库一平台"核查在建情况
  • 业绩双证齐全：合同+竣工验收缺一不可
  • 履约保证金优先银行保函（占用授信少）

2.2 货物招标

设备 / 材料 / 系统集成 / 软硬件采购
参数控标
  • "★"号条款（实质性）逐条响应，缺一条即废
  • 参数倾向性：特定品牌参数需用"或同等品质"软化
  • 参数负偏离：低于要求即失分，重大负偏离即废
  • 关键技术参数须第三方检测报告支撑
原厂授权/代理
  • 代理商必须提供原厂授权书
  • 授权层级：一级/二级代理权限不同
  • 有效期：覆盖投标有效期+履约期
  • 售后承诺函：原厂或授权机构出具
检测报告时效
通常3年内有效（部分1年）；机构须CMA/CNAS；参数对应、型号一致
知识产权连带
侵权投标人担全责；软件需正版/著作权；硬件需专利避免仿冒；中标后兜底
交货期与调试
交货期为实质性条款；安装调试责任/费用/验收划分；培训要求；备品备件清单
应对策略
  • 参数响应表逐条核对：每★号条款须"满足/优于"
  • 检测报告提前梳理：3年内CMA/CNAS，参数型号一致
  • 原厂授权提前申请：层级/有效期/范围核对
  • 知识产权自查：专利/软著避免侵权

2.3 服务招标

咨询 / 物业 / 安保 / IT服务 / 政府购买服务
人员证书得分
  • 一建/PMP/高级职称/信息系统项目管理师/注册咨询师
  • 证书有效且注册单位与投标人一致
  • 数量/等级/专业方向匹配评分办法
  • 社保连续缴纳（通常6个月-1年）
负责人履历
  • 类似项目经验：规模/类型/角色
  • 工作年限：通常5-10年以上
  • 证书：高级职称+行业执业资格
  • 无在建冲突项目
类似业绩证明
合同 + 用户证明双件齐全；用户证明需甲方盖章含服务内容/期限/质量评价；金额/类型/期限匹配
社保真实性
核心人员社保连续（6个月以上）；缴纳单位须一致；临时挂证易查出；变更需建设单位同意
方案可执行性
忌空话套话；须有流程/人员配置/应急预案；标准量化（响应/解决时间）；承诺可考核（KPI/违约）
应对策略
  • 人员证书矩阵化管理：证书/社保/履历建卡避免复用
  • 业绩档案双件齐全：按行业/规模/金额分类归档
  • 社保一致性核查：投标前查所有核心人员缴纳单位
  • 方案模板化+个性化：避免千篇一律低分

2.4 政府采购

各级国家机关 / 事业单位 / 团体组织 · 财政性资金
中小企业声明函
  • 强制提交（财库〔2020〕46号第11条；声明函为唯一身份证明文件）
  • 价格扣除：货物/服务小微 10%-20%（财库〔2022〕19号）；工程项目 3%-5%（财库〔2020〕46号）
  • 联合体/分包：货物服务 4%-6%（19号文）；工程 1%-2%
  • 造假 = 提供虚假材料谋取中标（46号文第20条 / 政采法第77条）→ 处罚+列入不良行为名单
进口产品审批
原则采国货；确需进口：财政部审批+专家论证+公示；关境外生产算进口；中外合资不算
节能产品清单
强制/优先采购按"节能产品政府采购品目清单"执行（财库〔2019〕9号 + 19号，★号品目强制）；凭有效期内的节能产品认证证书；品目清单动态调整，投标前核对现行版本
信用中国查询
不得为失信被执行人/重大税收违法/政采严重违法失信（财库〔2016〕125号，投标截止时点查询）；资格条件要求投标前3年内无重大违法记录（政采法第22条，定义见实施条例第19条）；失信名单公布期一般3年（财办库〔2014〕526号）
政策功能
监狱企业/残疾人单位视同小微；支持脱贫农副产品；创新产品首购订购
应对策略
  • 声明函模板化：严格按财政部模板，数据真实
  • 进口审批提前规划：周期2-3个月
  • 节能清单实时更新：投标前核对产品在列
  • 信用中国截图存档：投标前1周内查询

2.5 EPC / PPP

工程总承包 / 政府和社会资本合作 / 特许经营
联合体责任
协议明确设计/施工责任边界；各方承担连带责任；牵头方代表投标/签约/履约；成员变更需同意且资质不低于原
融资可行性
  • 银行授信函：覆盖总投资50%以上
  • 融资方案：来源/结构/还款计划
  • 自有资金：覆盖20-30%
  • 能力评估：资产负债率/流动比率/现金流
绩效与付费
按绩效付费：可用性+运营绩效；建设期/运营期分别设指标；付费风险（能力/延迟）；调价机制（物价/汇率/利率）
全周期成本
建设+运营+维护+拆除；折现率6-8%；周期15-30年；精度±10%以内
风险分担
政策风险政府担；汇率政府担/共担；工期社会资本担；不可抗力共担；须在合同中明确
应对策略
  • 联合体协议精细化：责任/权利/收益明确
  • 融资方案提前对接银行：授信/承诺/意向函分层
  • 绩效指标分别谈判：避免指标过高
  • 成本测算模型化 + 风险逐项谈

第三章决策前哨 · 四步定盘

拿到招标文件，第一件事不是写标书，而是用四步法定盘——判断该不该投。

STEP 01

定方式 · 属于哪种采购

是否使用财政性资金？
├─ 是 → 政府采购法管辖
│   ├─ 限额以上 → 公开招标（默认）
│   ├─ 特殊性质 → 邀请招标
│   ├─ 技术复杂/服务类 → 竞争性磋商
│   ├─ 紧急/技术不确定 → 竞争性谈判
│   ├─ 标准现货货物 → 询价
│   └─ 唯一供应商 → 单一来源
└─ 否 → 招标投标法管辖
    ├─ 限额以上 → 公开招标（默认）
    ├─ 特殊性质 → 邀请招标
    └─ 其他方式参照政府采购
  • 资金性质：财政性 vs 国有 vs 社会
  • 项目金额：是否达限额
  • 项目性质：保密/紧急/技术复杂
  • 供应商数量：是否唯一
STEP 02

定行业 · 属于哪个赛道

采购对象是什么？
├─ 工程建设（施工/勘察/设计/监理）→ 工程招标
├─ 货物（设备/材料/系统）→ 货物招标
├─ 服务（咨询/物业/IT/安保）→ 服务招标
├─ 财政性资金采购 → 政府采购（叠加政策功能）
└─ 工程总承包/特许经营 → EPC / PPP
  • 采购对象：工程/货物/服务/综合
  • 是否叠加政采政策功能
  • 是否涉及融资/运营/绩效付费（EPC/PPP特征）
STEP 03

查废标条款 · 逐条核

废标条款来源：①"投标无效条款"章节 ②"实质性条款"清单（★号） ③"资格要求"章节 ④法律法规强制性规定

  • 资质证书齐备且有效？
  • 业绩达标（合同+验收/用户证明）？
  • 人员证书齐全且可锁定？
  • 实质性条款逐条响应？
  • 投标保证金按时到账？
  • 投标文件按时递交？
  • 中小企业声明函合规（政采）？
  • 信用中国无失信记录？
STEP 04

算匹配度 · 资质/业绩/人员/财力

维度权重评估要点
资质匹配度25%资质等级、专项资质、行业许可
业绩匹配度30%类似项目数量、金额、类型、时间
人员匹配度30%项目经理、技术负责人、核心团队证书
财力匹配度15%营收规模、资产负债率、现金流、融资能力
匹配度阈值： ≥ 80分 高匹配必投 ｜ 60-80分 中匹配评估后决策 ｜ < 60分 低匹配建议放弃（除非有定向优势）

第一部分补充控标识别实战 · 识破"萝卜招标"

控标（业内称"萝卜招标"）指招标人通过文件设计让特定投标人中标。这是决策闸门最隐蔽的坑：表面合规，实质已内定。投标助手的核心能力之一，就是在投之前识别它——你是去竞争，还是去陪标。

形态一

需求源头预埋

  • 操作端口前移至立项/需求调研阶段，招标人与意向企业提前串通
  • 把企业独有技术、专属业绩、定制服务标准直接纳入采购需求
  • 后续招标仅走流程，从源头锁定中标对象
  • 例：安全负责人加分条件仅指向本地少数企业；要求不存在的市级科技奖项
形态二

招标文件伪装（隐性设限）

  • 非标参数模糊化：改用"具有某专利技术""近3年3项单项超5000万业绩"等非标准要求，仅意向企业满足
  • 资质奖项冗余化：叠加无关资质（如普通货物要求ISO 50001能源体系）、本地化服务要求（本地办公满5年）
  • 标段拆分刻意化：合并为亿元级"巨无霸"排除中小企业，或拆分仅本地企业可承接
形态三

评审规则倾斜

  • 评分权重失衡：把权重压向意向企业优势项
  • 倾向性评分细则：模糊主观分项、特殊加分项
  • 操控评标专家：人情分、关系分

识别信号清单（红旗）

信号表现合规边界
参数指向单一品牌特定型号/专利，缺"或同等品质"软化政府采购法实施条例第二十条禁止
业绩门槛过窄金额/时间/范围无依据且极窄应具合理性、不排斥潜在投标人
资质与需求错配过低（形同虚设）或过高（量身）应与项目实际需要相适应
本地化硬要求本地办公场所、本地业绩年限无正当理由限制外地企业违法
非权威认证/奖项加分特定非权威诚信认证、虚构奖项不得作为排斥性条件
权重异常主观分项占比畸高、指向性打分权重应反映项目核心需求
应对：拿标书先做"控标体检"——发现2条以上红旗即可判定高风险。依据《政府采购法实施条例》第二十条提质疑/投诉，留存证据链；若非意向方且无破解空间，建议放弃，避免烧钱陪标。

第二部分吃透招标文件 · 规则怎么玩

第一部分是"该不该投"（决策闸门），第二部分回答"游戏规则怎么定"——不读透招标文件，方案写偏、力气用错地方，等于在错误的赛道上狂奔。本章四块递进：前附表精读 → 评标办法拆解 → ★号实质性条款锁定 → 隐性坑族谱。

2.1 投标人须知前附表 · 总纲地图

前附表是招标文件的"压缩包"——把工期、质保、保证金、有效期、递交方式、废标索引等生死节点浓缩成一页。它排在正文之前，却决定你读文件的顺序。

前附表必看字段对应风险 / 动作
投标有效期通常≥90天，不足即废（见速记卡⑤）
保证金金额与形式金额 / 到账时限 / 基本户要求，错一处即废（速记卡②）
递交截止与方式电子标上传 vs 纸质递交，超时=0分
评标办法指向直接跳到 2.2，决定力气往哪使
废标 / 无效投标索引浓缩版雷区，与附录A对照看
关键时间节点答疑截止、澄清、开标——错过=被动
动作：拿到文件第一件事——把前附表逐格抄成"自查清单"，每格打钩才能进下一环节。

2.2 评标办法拆解 · 力气往哪使

评标办法告诉你"分怎么算"。读懂它，才知道方案写多深、报价怎么报。两大主流：

最低评标价法（最低价法）

满足实质要求 · 报价最低者中标
适用
  • 通用技术、标准统一（标准货物 / 工程）
  • 国际默认、客观量化、难围标
你的打法
价格定生死，商务技术只过门槛——别在方案上堆花，省钱 + 合规即胜

综合评分法（综合法）

满足实质要求 · 量化得分最高者中标
适用
  • 技术复杂 / 服务 / 工程
  • 价格分 + 技术分 + 商务分加权
你的打法
逐条拆评分表，找满分点、凑满分；主观分最容易丢，需针对性拆解

价格分公式（综合法 · 低价优先法）

公式 · 87号令第五十五条

投标报价得分 = (评标基准价 / 投标报价) × 价格权值 × 100

评标基准价 = 满足招标文件要求的最低投标报价（得满分）
价格分值（招标·87号令第55条）：货物 ≥30% ｜ 服务 ≥10%（仅设下限，无上限）
价格权值（竞争性磋商·财库〔2014〕214号第24条）：货物 30%-60% ｜ 服务 10%-30%
报价越低分越高，但低于成本警戒线 = 废（可要求澄清证明）
  • 价格权重下限是法定红线，招标文件不得突破
  • 评标不得去掉最高 / 最低报价（防操纵）
  • 落实政策（中小企业等）的价格扣除，以调整后价格计算
关键动作：把评分表逐条拆成"我能拿满分 / 拿部分 / 拿不到"，排优先级。技术分里的"主观分"（如方案创新性0-5分）最易丢——对策：把招标技术需求逐条抄进方案，每条后写"解决方案：…"，让评委扣分都找不到理由。

2.3 实质性条款（★号）锁定 · 踩一条全盘输

实质性条款 = 不可偏离的"硬杠"。招标文件用 ★号、黑体、"废标 / 无效投标" 醒目标明。任一负偏离 / 漏响应 = 直接否决，评委无自由裁量空间。

类别常见★号内容
准入资格资质等级 / 财务状况 / 类似业绩 / 信用记录（硬门槛）
标的核心核心技术参数 / 交付标准 / 验收等级（负偏离即否决）
商务核心投标有效期 / 工期 / 质保期 / 付款条件 / 违约责任
程序合规签署 / 密封 / 保证金缴纳（不符直接拒收）
铁律（87号令第二十条 / 第三十二条、实施条例第三十三条）：未明确标注为实质性的内容，不得作为否决依据；但凡标了★，必须逐条明确"无偏离响应"并配佐证。哪怕 CPU 主频只低 0.1GHz、噪声只高 1dB，电子评标系统结构化比对后刚性否决——"微小负偏离"无豁免口子。
实操清单：① 摘出所有★号条款，建"实质性条款响应表"；② 逐条写"完全响应 / 无偏离" + 佐证材料位置；③ 技术偏离表写"无偏离"，绝不写"见检测报告""略低"等模糊词——系统会判负偏离亮红灯。

2.4 隐性坑族谱 · 模糊表述与软壁垒

显性坑（★号）看得见，隐性坑藏在"字越正经、坑越要命"的模糊表述和软壁垒里。它们往往和第一部分"控标识别"呼应——这里是识别后的证据收集。

隐性坑类型话术表象真实陷阱应对
付款软刀子"竣工验收后付至97%"没写几天 → 拖延尾款书面提问明确期限
参数定制绑架"需XX品牌A100芯片"量身定做，替代即不响应质疑要求允许同等替代
评分模糊杀人"方案创新性0-5分"无标准，主观分随意逐条抄需求写方案
软壁垒堆叠非标认证 / 特定专利 / 本地设点变相抬高门槛质疑投诉
偏离项数陷阱未明确允许偏离项数一般性条款稍改即淘汰要求明确项数
清单钓鱼"土方暂定10万方"实际6万，单价包死亏穿不平衡报价 + 备注
应对四式：① 标前书面质疑（答疑截止前，把水搅浑）；② 报价埋伏（不平衡报价 + 备注声明）；③ 合同预埋（中标后谈判替代条款）；④ 证据链保命（质疑函 / 澄清回复纸质盖章留存）。

⚠️ 隐性坑识别后，回到第一部分「控标识别实战」判断是否"萝卜招标"，二者构成质疑 / 投诉的证据链。第三部分「响应合规与格式」将展开暗标13条红线——那是另一类"写了就废"的格式坑。

第三部分 · 响应合规与格式

一条踩雷，全盘皆输 —— 暗标泄露公司名、盖章漏签、★号没响应，都是"写了就废"的格式坑

优先级：③ 响应合规与格式 定位：合规入场·一票否决重灾区 标注：✅依据 / 🔶实践惯例
本部分定位：投标工作优先级框架第③层。第①②层解决"该不该投、规则怎么读"，本层解决"怎么交才不被废"——技术/商务内容再漂亮，格式踩雷直接出局。核心三件事：暗标13条红线（身份不泄露）→ 实质性响应（★号不踩雷）→ 装订密封（程序零失误）。

3.1暗标13条红线 · 身份零泄露自查清单

暗标 = 技术标隐去一切可识别身份信息，评委盲评打分。任一条红线踩中 = 直接废标，无自由裁量空间。

⚠️ 适用范围：以下13条是行业通行实践汇总（🔶，具体以本项目招标文件"暗标要求"章节为准）。招标文件怎么写，就按什么标准自查——它可能更严，不会更松。
红线 01-04 · 身份信息
  • 01 公司名称/简称/Logo：正文、封面、页眉页脚均不得出现
  • 02 人员信息：项目负责人、技术负责人、任何人员姓名、证书编号
  • 03 联系方式：地址、电话、邮箱、网址、公众号
  • 04 可识别痕迹：照片、印章、签名、专属水印、特殊图案
红线 05-09 · 版面格式
  • 05 字体字号：全篇统一（正文常用宋体小四/仿宋，按文件约定）
  • 06 行距段距：全篇一致，不得差异化缩进暗示
  • 07 页码：连续统一，位置/格式一致
  • 08 标记：不得做任何符号、颜色、高亮、加粗等特殊标记
  • 09 涂改粘贴：不得涂改、刮擦、粘贴覆盖、夹带纸条
红线 10-13 · 封装与电子
  • 10 封面统一：暗标封面按招标文件统一格式，不写公司名
  • 11 密封：暗标密封袋/信封按文件要求，密封处不得署名
  • 12 电子文档属性：清除作者/创建者/公司信息（Word/PDF元数据）
  • 13 超链接/嵌入：不得含暴露身份的链接、嵌入对象、宏
自查动作：① 技术标全文搜索公司名/人员名/电话/邮箱（Ctrl+F 逐个清）；② 检查页眉页脚、封面、目录；③ 检查文档属性（文件→信息→属性，清除作者与公司）；④ 导出 PDF 后再全文检索一遍——很多公司是"Word里删了、PDF里没更新"。

3.2实质性响应写法 · ★号条款无偏离表

实质性条款 = 不可偏离的"硬杠"（★号、黑体、"废标/无效投标"醒目标明）。任一负偏离/漏响应 = 直接否决。

法律依据（✅）：《招标投标法》第27条——投标文件应当对招标文件提出的实质性要求和条件作出响应；87号令第32条——未明确标注为实质性的内容，不得作为否决依据（即：标了★必须逐条响应）。
标准写法 · 无偏离表

逐条"完全响应 / 无偏离" + 佐证位置

  • 把招标文件所有★号条款摘出，建"实质性条款响应表"
  • 每条写"完全响应 / 无偏离"，并注明佐证材料所在页码/章节
  • 技术偏离表一律写"无偏离"——绝不写"见检测报告""略低""基本满足"等模糊词
  • 电子评标系统会做结构化比对：微小负偏离（如主频低0.1GHz、噪声高1dB）也可能被刚性否决
  • 偏离表填"无偏离"但实际参数不满足 = 虚假响应（重大风险），必须在投标前逐项核对产品/方案真实参数
★号条款四大类
  • 准入资格：资质等级/财务状况/类似业绩/信用记录
  • 标的核心：核心技术参数/交付标准/验收等级
  • 商务核心：投标有效期/工期/质保期/付款条件/违约责任
  • 程序合规：签署/密封/保证金缴纳
三条铁律
  • 铁律一：★号无豁免口子，负偏离即否决（87号令第20条）
  • 铁律二：未标★的内容不得作否决依据（87号令第32条）——但别赌"没标★就不管"
  • 铁律三：响应表与正文要一致，正文参数必须真实达标

3.3签字 · 盖章 · 装订 · 密封清单

程序性动作最容易在最后关头翻车。以下为通行实务清单（🔶），以招标文件"投标文件编制要求"章节为准。

法律依据（✅）：《招标投标法实施条例》第51条第（一）项——投标文件未经投标单位盖章和单位负责人签字的，评标委员会应当否决其投标。第36条——逾期送达或未按要求密封的，招标人应当拒收。

第四部分 · 报价策略

算账报价，胜负手 —— 报低了亏本甚至废标，报高了丢分出局。报价是一门"反推"的学问

优先级：④ 报价策略 定位：算账报价·利润与得分平衡 标注：✅依据 / 🔶实践策略
本部分定位：投标工作优先级框架第④层。前3层解决"该不该投、规则怎么读、怎么交不废"，本层解决"报多少能赢、还能赚"。核心链条：测算限价 → 反推价格分 → 守住成本底线 → 把握磋商谈判节奏。报价策略是🔶实践方法 + ✅法定红线（低于成本、高于限价、最低投标限价禁止）共同约束下的决策。

4.1最高限价测算与拆解

最高限价（最高投标限价）是报价的"天花板"——测算它，才知道利润空间在哪。

法律依据（✅）：《招标投标法实施条例》第27条——招标人设有最高投标限价的，应当在招标文件中明确最高投标限价或者最高投标限价的计算方法。招标人不得规定最低投标限价。
限价拆解 · 成本倒推
  • 直接成本：人（人工）、材（材料）、机（机械）——按工程量/清单测算
  • 间接成本：管理费、规费、现场经费
  • 税金：按现行税率计取
  • 利润：行业平均利润率区间（🔶 参考），据此判断空间
限价 → 报价区间
  • 上限：最高投标限价（超过即废，实施条例51条）
  • 下限：自己的成本底线（低于即亏本/可能被认定低于成本）
  • 有效报价区 = 成本底线 ~ 最高限价（再叠加价格分最优区间）
  • 🔶 服务/货物类可结合预算与市场行情横向比价

4.2价格分反推最优报价区间

读懂价格分公式，就能反推出"报多少拿多少分"——价格分是综合评分法里最可计算的分数。

公式 · 低价优先法（✅ 87号令第55条）

投标报价得分 = (评标基准价 ÷ 投标报价) × 100

评标基准价 = 满足招标文件要求的最低有效投标报价（得满分）
评标过程中不得去掉最高/最低报价
落实政策的价格扣除（如中小企业），以调整后价格计算
价格分权重下限：招标货物 ≥30%、服务 ≥10%（仅设下限，无上限）
（竞争性磋商按财库〔2014〕214号第24条：货物30%-60%、服务10%-30%）
  • 反推逻辑（🔶）：基准价=最低报价 → 报价越接近最低者，价格分越高
  • 最低报价者价格分满分；第二名 = (最低价÷自己报价)×100
  • 若最低价压得很低，次低价价格分被拉低 → 别盲目拼最低
分档报价法（🔶）
  • 先估竞争对手最低价区间（历史价/市场行情）
  • 算不同报价下的价格分差距 vs 成本增加
  • 找"分数性价比最高"的报价点——每降1%价格，分差/利润损失比
  • 非最低价策略：靠技术/商务分弥补价格分差
价格分权重的影响
  • 权重高（≥50%）：价格定生死，报价尽量贴近最低
  • 权重低（30%左右）：技术分是主战场，报价留利润空间
  • 货物 ≥30%、服务 ≥10% 是法定下限（87号令55条）
  • 🔶 招标文件会写明价格分算法，先算清再报价

4.3成本底线与低价警戒

"低价中标"是双刃剑——低于成本报价是法定禁区，且可能被要求澄清证明。

法律依据（✅）：《招标投标法》第33条——投标人不得以低于成本的报价竞标。《招标投标法实施条例》第51条第（五）项——投标报价低于成本或者高于招标文件设定的最高投标限价的，评标委员会应当否决其投标。
成本底线测算（🔶）
  • 按"个别成本"测算（自己的成本，非行业平均）
  • 直接成本 + 应分摊的间接费用 + 合理利润临界
  • 留出风险金：材料波动、工期顺延、变更扣减
  • 成本底线之上才报，守住"不亏"红线
低价被质疑的应对
  • 报价明显低于其他投标人 → 评标委员会要求书面澄清/说明
  • 需提供证明材料：成本构成、采购渠道、报价依据
  • 不能合理说明或不能提供证明 → 认定低于成本报价 → 否决
  • 🔶 提前备好"低价说明"底稿，别在评标时现编
策略平衡：价格分要求"低"，成本底线要求"高"——最优报价 = 成本底线之上、价格分最优区间之内的交集。若两者无交集（成本底线已高于对手可能报价），说明该标利润空间被压死，回到第一部分「决策前哨四步」重新评估是否放弃。

4.4磋商 / 谈判报价节奏

非招标方式的价格博弈：磋商重"方案+综合评分"，谈判重"最后报价最低成交"。节奏与底线缺一不可。

竞争性磋商（🔶 · 财库〔2014〕214号）
  • 多轮磋商明确需求，最后报价密封提交
  • 综合评分法：价格分按权值（货物30%-60%、服务10%-30%）
  • 节奏：首轮报高留空间（10-15%），末轮一锤定音
  • 最终报价不得超磋商范围/预算，超了即废
  • 磋商意见书面留痕，响应逐条对应
竞争性谈判（🔶 · 74号令）
  • 多轮谈判，最后报价最低者成交（符合实质要求）
  • 节奏：首轮高成本30-40%，末轮贴成本底线
  • 绝不主动透露成本/底价——泄露即被对手参考
  • 最后报价超采购预算即废；多家同价需再报或抽签
本部分小结：报价不是"拍脑袋"，是算出来的——测算限价定空间、反推价格分定靶点、守住成本底线定红线、把握磋商谈判定节奏。下一部分（方案编制）解决"技术分怎么拿满"。
