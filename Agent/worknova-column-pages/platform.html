01 · AGENT FACTORY

像搭积木一样，创建你的 Agent

按业务场景创建、配置、部署 Agent，无需写代码即可组合所需能力。支持招聘、运维、客服、销售、运营、行政等场景类型；每个 Agent 都有独立的职责、知识库、SOP 和工具权限。

  • 场景模板预置多种业务场景模板，作为创建起点。
  • 角色配置定义 Agent 角色、职责和权限范围。
  • 知识库挂载上传企业资料，供 Agent 学习和检索。
  • SOP 编排把稳定流程整理为标准操作程序。
  • 技能管理为 Agent 绑定工具和技能包。
  • 部署管理按接入方案部署到飞书、企微、钉钉等渠道。

02 · TASK EXECUTION ENGINE

  5. 05产物生成结果并归档
  6. 06扣费记录任务用量
  7. 07日志回查运行过程

03 · KNOWLEDGE & MEMORY

让 Agent 越用越懂你的业务

上传企业资料，Agent 在任务中检索和参考。把业务规则、稳定流程与历史任务经验沉淀下来，供不同 Agent 按授权范围复用。

  • 知识库支持 PDF、Word、Excel、网页与文本，结合 RAG 检索增强。
  • 长期记忆沉淀用户偏好、业务规则和历史任务结果。
  • SOP 流程整理招聘评估、运维巡检、客户跟进等稳定流程。
  • 版本管理为知识和 SOP 管理版本及生效范围。
  • 权限控制按 Agent 配置可访问的知识范围。

04 · TOOLS & SKILLS

内置 100+ 企业工具，技能可复用、可共享

连接飞书表格、消息、文件、API、数据库、工单系统等企业常用工具。Skill 技能包可组合成可复用能力，便于在不同 Agent 间共享。

LAYER 01

Tool 最小动作

组成任务步骤的基础操作单元。

示例查知识库 · 发飞书消息 · 调接口 · 读文件
LAYER 02

Skill 可复用能力包

把多个 Tool、规则与提示词组合成可复用流程。

示例合同审核 Skill = 查知识库 + 条款比对 + 生成报告
LAYER 03

MCP 外部系统接入

以标准方式接入企业现有系统的外部能力。

示例ERP · CRM · OA 等现有业务系统
